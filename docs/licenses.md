# データ出典とライセンス

本プロジェクトが使用する全データの利用条件。**ライセンスが不明なデータは使用しない**方針です。

出典表示はコードの 1 箇所（`packages/shared/src/attribution.ts`）に定義され、
UI が自動的に列挙します。新しいデータソースを追加するときは必ずここに定義を足してください。
「使ったのに表示していない」を構造的に防ぐための設計です。

### PLATEAU-Terrain（地形配信）

`https://tile.plateauview.mlit.go.jp/terrain/layer.json` のレスポンスに含まれる
attribution をそのまま表示しています: `PLATEAU | Mapterhorn | 国土地理院`

なお PLATEAU 配信サービスは**実験的サービス**であり、提供期間・水準は保証されていません。

## 2. OpenStreetMap（道路・POI・経路）

| 項目 | 内容 |
| --- | --- |
| ライセンス | **ODbL 1.0**（Open Database License） |
| 出典表示 | `© OpenStreetMap contributors` |
| URL | https://www.openstreetmap.org/copyright |

守るべき条件:

- 地図表示・検索結果・経路など、OSM 由来のすべての表示に帰属表示が必要。
- **派生データベースを公開・配布する場合は share-alike（同一ライセンスでの提供）義務**が生じます。
  `scripts/import-osm` が生成する SQL / GeoJSON は OSM の派生データベースにあたるため、
  配布する場合は ODbL に従ってください（`data/` は Git 管理外にしています）。

### 公開インスタンスの利用ポリシー

| サービス | ポリシー |
| --- | --- |
| Nominatim | 1 リクエスト/秒、識別可能な User-Agent が必須、結果のキャッシュ推奨 |
| Overpass API | 自動負荷制御によるレート制限あり。大量利用はセルフホスト |
| FOSSGIS Valhalla | 1 req/user/秒・合計 100 req/秒。公開アプリからは `X-Client-Id` ヘッダの付与が求められる |

本アプリはいずれも実装済みです（スロットル・User-Agent・`X-Client-Id`・キャッシュ）。
それでも公開デモは本番用途には向きません。セルフホストしてください。

## 5. 3D アセット（装飾）

現時点で**外部生成の 3D アセットは同梱していません。**

街路樹・街灯・ベンチは、以下のルールで描画しています。

- **位置**: OpenStreetMap の `natural=tree` / `highway=street_lamp` / `amenity=bench`（＝実在位置、ODbL）
- **形状**: アプリ内で手続き的に生成した軽量ジオメトリ（位置に対して決定的）

将来 AI 生成や外部配布のアセットを追加する場合は、次を必須とします。

1. glTF 2.0 / GLB 形式、PBR マテリアル
2. `data/assets/LICENSES.md` にアセット単位でライセンス・出典・商用可否を記録
3. **ライセンス不明のモデルは使用しない**
4. 実在建物の位置・形状の代替としては使用しない（装飾のみ）

## 6. 使用していないもの

以下は本プロジェクトでは**一切使用していません**。

- Google Maps のコード・データ・3D データ・UI デザイン
- Google の非公開 API
- スクレイピングで取得した地図データ
- ライセンス不明の 3D モデル
